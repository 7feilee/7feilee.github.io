Save encrypted backup

Protects your file with AES-256-GCM encryption

Encrypted with AES-256-GCM + PBKDF2-SHA256 · 600,000 iterations
Decrypt offline without a browser ►

Replace PASSPHRASE with your passphrase. The filename is shown in the download prompt.

Node.js (no install needed)
node -e "const d=require('fs').readFileSync('master_key.enc'),c=require('crypto');const k=c.pbkdf2Sync('PASSPHRASE',d.slice(5,37),600000,32,'sha256'),g=c.createDecipheriv('aes-256-gcm',k,d.slice(37,49));g.setAuthTag(d.slice(-16));process.stdout.write(g.update(d.slice(49,-16),'','utf8')+g.final('utf8'))"
Python (pip install cryptography)
python3 -c "import hashlib;from cryptography.hazmat.primitives.ciphers.aead import AESGCM;d=open('master_key.enc','rb').read();k=hashlib.pbkdf2_hmac('sha256',b'PASSPHRASE',d[5:37],600000);print(AESGCM(k).decrypt(d[37:49],d[49:],None).decode())"

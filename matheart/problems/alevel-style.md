# A-Level 精讲：驻点问题的满分模板

> 这类题在 9709 Pure 1 / Edexcel Pure 里年年出现，人人都"会做"——
> 但 mark scheme 面前，"会做"和"满分"是两回事。这一篇给你满分的写法。

## 题目

曲线 $y = x^3 - 3x^2 + 4$。

1. 求曲线的驻点（stationary points），并判断其性质；
2. 画出曲线草图，标出与坐标轴的所有交点。

## 第 (1) 问：满分写法

**第一步 · 求导（M1）**

$$\frac{\mathrm{d}y}{\mathrm{d}x} = 3x^2 - 6x$$

**第二步 · 令导数为零并解方程（M1 A1）**

$$3x^2 - 6x = 0 \;\Rightarrow\; 3x(x-2) = 0 \;\Rightarrow\; x = 0 \;\text{或}\; x = 2$$

代回原式求 $y$：驻点为 $(0, 4)$ 与 $(2, 0)$。 **（A1 —— 注意：只给 $x$ 不给 $y$ 要扣分）**

**第三步 · 判断性质（M1 A1）**

$$\frac{\mathrm{d}^2y}{\mathrm{d}x^2} = 6x - 6$$

- 在 $x=0$：$y'' = -6 < 0$，故 $(0,4)$ 为**极大值点**（maximum）
- 在 $x=2$：$y'' = 6 > 0$，故 $(2,0)$ 为**极小值点**（minimum）

> **扣分高发区**：写了 $y''$ 的值却不写结论；或写"maximum"却不注明是哪个点。
> mark scheme 的原话通常是 *"correct conclusion with supporting working"*——结论和依据缺一不可。

## 第 (2) 问：草图的得分点

先求交点。令 $y = 0$：

$$x^3 - 3x^2 + 4 = 0$$

试根 $x = -1$：$-1 - 3 + 4 = 0$ ✓。因式分解：

$$x^3 - 3x^2 + 4 = (x+1)(x^2 - 4x + 4) = (x+1)(x-2)^2$$

所以曲线交 $x$ 轴于 $x = -1$（穿过）和 $x = 2$（**重根 → 相切**）；交 $y$ 轴于 $(0, 4)$。

草图必须体现的四件事（每件都是采分点）：

1. 三次曲线的整体走向（左下 → 右上）
2. $(-1, 0)$ 处**穿过** $x$ 轴
3. $(2, 0)$ 处**触碰不穿过**（既是重根又是极小值点——两个信息互相印证）
4. $y$ 轴截距 $(0,4)$ 标注清楚

## 这道题的"隐藏考点"

注意到了吗——极小值点 $(2,0)$ **恰好落在 $x$ 轴上**，与二重根 $x=2$ 是同一件事。
出题人埋这种自洽结构，就是想看你会不会用第 (1) 问的结果去校验第 (2) 问。
**做完能自我验证，是 A\* 学生和 A 学生最稳定的区别。**
